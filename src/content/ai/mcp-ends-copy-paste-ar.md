الـ AI مش متوصل بأدواتك. فكل حاجة copy/paste.

تسأل ChatGPT حاجة. تاخد الإجابة copy وتحطها في Notion. تاخد من Notion copy وترجع تحطها في ChatGPT. ساعة شغل، ومعظمها نقل كلام من tab لـ tab.

MCP بينهي ده. ازاي؟

## إنت الوصلة

الـ AI ذكي، بس محبوس جوه الشات. مش شايف صفحة Notion بتاعتك. مش قادر يفتح الـ issues اللي على Linear. مش بيقرا الـ thread اللي على Slack. فإنت اللي بتبقى الوصلة: بتدخّل له المعلومة بإيدك، وبتطلّع الإجابة بإيدك.

ده مش شغل تفكير. ده شغل شيل وحط. وفيه تمن تاني كمان: الـ AI مابيعرفش غير اللي إنت افتكرت تعمله paste. نسيت صفحة؟ يبقى الإجابة اتبنت على نص الصورة.

## يعني إيه MCP

MCP اختصار Model Context Protocol. ده protocol مفتوح: طريقة standard واحدة الـ AI app يكلّم بيها أي tool.

هو حتتين. الـ tool بتعمل **MCP server** مرة واحدة. الـ server ده بيقول للـ AI يقدر يعمل إيه هناك: يدوّر في الصفحات، يعمل صفحة جديدة، يعدّل issue، يبعت رسالة. وبعدين أي AI app بيتكلم MCP يقدر يستخدمه. Claude، ChatGPT، Cursor. server واحد، لكل الـ apps.

Anthropic طلّعته في نوفمبر 2024. وفي 2025 OpenAI وGoogle دعموه هما كمان. وده اللي مخليه مهم: مش feature بتاعة شركة واحدة. ده الـ standard.

Notion ليها MCP server. Linear ليها. Slack ليها. Gmail ليها.

## بيقرا وبيكتب

دي النقطة اللي ناس كتير بتفوّتها. MCP مش للقراية بس.

**بيقرا:** يفتح صفحة Notion، يجيب الـ issues المفتوحة من Linear، يقرا الـ thread على Slack، يلاقي الإيميل.

**بيكتب:** يعمل الصفحة، يعمل update على الـ issue، يبعت الرسالة.

وكله من جوه الشات. تيجي تطلب خطة على Notion، وupdate على Linear، وupdate للتيم على Slack. وبيتعمل. تلات tools، رسالة واحدة، ومفيش copy/paste.

> MCP، عصر جديد. الـ copy/paste، عصر قديم.

الفرق مش إن الـ AI بقى أذكى. الفرق إنه بقى يقدر يشتغل جوه أدواتك. زمان الـ AI كان بيجاوب وإنت تنفّذ. دلوقتي هو اللي بينفّذ، وإنت اللي بتراجع.

## بس خلي بالك

الاتجاه أنا متأكد منه. التفاصيل عايزة شوية حرص.

- **هو بيشتغل باسمك.** إنت بتوصّله بالأكونت بتاعك، فيقدر يوصل لكل حاجة إنت تقدر توصلها. وصّل اللي محتاجه بس، مش كل حاجة.
- **الغلط بقى بيتنفّذ بجد.** زمان الإجابة الغلط كانت بتموت في الشات. دلوقتي ممكن تلاقيها على الـ board بتاعك في Linear. خليه يوريك التعديل قبل ما يكتب.
- **MCP بيوحّد الوصلة، مش بيظبط الـ tool.** لو الـ Notion بتاعك مكركب، الـ AI هيقرا الكركبة. بس أسرع.

ولما عملت الـ reel ده في مايو 2026، ده اللي كنت شايفه: أي tool جديد يطلع، من أول الحاجات اللي بتنزل معاه MCP server. MCP بقى الـ default.

## جرّبها

اختار الـ tool اللي بتعمل فيها copy/paste أكتر حاجة، ووصّل دي بس.

في Claude app هتلاقيها في Settings، وبعدين Connectors. ولو بتستخدم Claude Code، هو سطر واحد في الـ terminal (اختار واحد بس):

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp

claude mcp add --transport http linear https://mcp.linear.app/mcp
```

وبعدين اكتب `/mcp` جوه Claude Code واعمل login.

وابدأ بالقراية، مش بالكتابة:

```text
إنت متوصل بالـ Notion بتاعي. قراية بس دلوقتي.
1. دوّر على صفحة "<اسم الصفحة>" واقراها.
2. طلّعلي الحاجات اللي لسه مفتوحة فيها، وكل واحدة مين مسؤول عنها.
3. اكتبلي مسودة الـ update اللي هبعتها للتيم عنهم.
ماتعملش ولا تعدّلش أي حاجة في Notion.
```

أول ما تثق في اللي بيقراه، سيبه يكتب. بس خلي قاعدة واحدة ثابتة في أي طلب كتابة: «ورّيني التعديل بالظبط الأول، واستنى موافقتي.»

الـ AI مش متوصل بأدواتك؟ وصّله. الـ copy/paste انتهى.
